# unbg studio 구현 계약

상태: 구현. 독립 개인 프로젝트의 신규 spec. Dropshot 앱·패키지에는 영향 없음.

## 목표와 제외

피사체가 정렬된 서로 다른 단색 배경 이미지 쌍을 여러 개 처리하고 투명 PNG를 일괄 저장한다. 단일 이미지 AI 추론, 유료 API, 서버 저장, 로그인, 이미지 영구 보관은 범위 밖이다.

## 데이터 소유와 상태

App이 이미지 쌍, 선택, 활성 미리보기, 전역 옵션을 소유한다. 원본 File과 Blob URL은 각 쌍에 연결된다. `idle → processing → done | error`, 중지된 작업은 idle, 이후 대기 작업은 그대로다. 처리 옵션 변경 또는 원본 교체는 해당 결과를 제거하고 idle로 돌아간다. 접미사·저장 이름만 변경하면 done 결과를 유지한다.

Worker는 한 쌍에만 존재하며 작업 종료, 취소, 120초 timeout에 종료된다. 개별 실패는 나머지 쌍 처리를 막지 않는다. 변환·ZIP 동안 변경 충돌을 일으키는 조작을 비활성화한다. PNG와 ZIP은 성공한 결과만 포함한다. ZIP 파일명은 전체 작업 공간 기준으로 중복 제거한다.

## 검증과 UI

확장자·크기 검증은 선택/교체 경로에서, 파일 signature·애니메이션 WebP·원본 알파·해상도·동일 크기 검증은 worker에서 수행한다. 배경색·범위·floor ≤ ceiling을 검증한 뒤 실행한다. unbg 오류는 사용자 조치가 가능한 한국어 안내로 표시한다.

추가할 때 패턴이 있는 이름은 자동 연결하고 그 외는 자연 정렬로 2장씩 연결한다. 홀수 파일은 B 빈 슬롯으로 남기며 변환 대상에서 제외한다. 사용자에게 원본 쌍 검토를 안내한다. 쌍은 최대 50개이므로 각 쌍 두 슬롯 합계도 100개를 넘을 수 없다. 결과 파일명에서는 이미지 확장자를 두 번 제거하지 않는다.

미리보기는 원본 A/B/변환 결과, 4가지 바탕, 확대를 지원한다. 바탕색은 PNG 픽셀에 영향을 주지 않는다. 저장 이름 입력, 원본 교체, 선택/전체 다운로드를 제공한다. 반응형 레이아웃, 키보드 포커스 표시, 명명된 입력, aria-pressed, 상태 알림, native dialog의 포커스 제어·Escape 닫기를 사용한다.

## 개인정보·운영

외부 이미지 전송, 인증, analytics 이벤트가 없다. 메모리 내 작업이며 새로고침 시 사라진다. CSP는 same-origin 스크립트, 이미지 blob/data, worker blob만 허용한다. 비공개 GitHub와 Vercel Hobby 개인 scope를 사용한다.

## 수용 시나리오

- 기본 예제 두 장으로 800×800 투명 PNG 생성. 투명 배경, 부분 알파, 불투명 영역 공존.
- 4장 이상 다중 업로드가 쌍 목록으로 연결되고 순차 변환되어 ZIP에 모든 PNG 포함.
- 같은 저장 이름인 여러 쌍에 번호가 붙고 점이 포함된 버전 이름이 유지됨.
- 선택 해제한 쌍은 선택 변환·선택 ZIP에서 제외. 완료 전체 ZIP은 모든 성공 결과 포함.
- HEX/RGB 배경색, 임계값, floor/ceiling, off/auto/threshold crop가 연산에 반영.
- floor > ceiling 등 잘못된 옵션은 변환 불가. 잘못된 원본은 오류 표시 후 다른 쌍 계속 처리.
- 중지하면 다음 작업이 시작되지 않고 이미 완성한 PNG를 저장 가능.
- 데스크톱·모바일에서 컨트롤이 넘치지 않고 가이드 닫기/옵션 조작 가능.
- 프로덕션 빌드·타입 검사·린트 통과. 배포 후 외부 접속과 worker/ZIP 흐름 확인.
