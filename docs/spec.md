# unbg studio 구현 계약

상태: 구현. 기본 배경 보존 형식 변환 및 선택형 단일 이미지 AI 모드 추가로 기존 spec 갱신. Dropshot 앱·패키지에는 영향 없음.

## 목표와 제외

배경을 유지하며 이미지 형식만 변환하거나, 사용자가 배경 제거를 켜면 단일 이미지를 로컬 무료 AI로 처리하거나, 피사체가 정렬된 두 단색 배경 이미지를 unbg로 비교해 투명 PNG를 일괄 저장한다. 기본은 convert(PNG), 배경 제거 OFF다. convert↔ai 전환은 작업이 있어도 가능하며 결과를 무효화한다. pair가 포함된 모드 전환은 작업 공간이 비어 있을 때만 가능하다. 예제 생성 중 모드 변경을 차단한다. 유료 API, 서버 저장, 로그인, 이미지 영구 보관은 범위 밖이다.

## 데이터 소유와 상태

App이 이미지 쌍, 선택, 활성 미리보기, 전역 옵션을 소유한다. 원본 File과 Blob URL은 각 쌍에 연결된다. `idle → processing → done | error`, 중지된 작업은 idle, 이후 대기 작업은 그대로다. 처리 옵션 변경 또는 원본 교체는 해당 결과를 제거하고 idle로 돌아간다. 접미사·저장 이름만 변경하면 done 결과를 유지한다.

Worker와 모델은 순차 작업 사이에 재사용된다. 취소, timeout(AI 600초 / 비교 120초), 런타임 오류, 작업 공간 비우기, 모드 변경, 앱 해제 시 종료된다. 진행 이벤트는 결과와 분리하며 다운로드 퍼센트·추론 단계 안내를 갱신한다. 모델 로딩 실패 시 초기화 Promise를 해제해 재시도할 수 있다. 개별 실패는 나머지 쌍 처리를 막지 않는다. 변환·ZIP 동안 변경 충돌을 일으키는 조작을 비활성화한다. 개별 저장과 ZIP은 성공한 결과만 포함한다. 모든 출력 이름은 실제 저장 형식의 확장자를 사용한다. ZIP 파일명은 전체 작업 공간 기준으로 중복 제거한다.

## 검증과 UI

확장자·크기 검증은 선택/교체 경로에서, 파일 signature·애니메이션 WebP·해상도 검증은 worker에서 수행한다. 원본 불투명·동일 크기 검증은 두 장 비교에만 적용한다. AI에서는 BRIA 예측 마스크를 min-max 정규화하고 floor/ceiling을 적용한 뒤 원본 알파에 곱해 기존 투명도를 유지한다. 배경색·범위·floor ≤ ceiling을 검증한 뒤 실행한다. unbg 오류는 사용자 조치가 가능한 한국어 안내로 표시한다.

convert와 AI는 파일 하나가 한 작업이며 최대 50장이다. 두 장 비교에서는 추가할 때 패턴이 있는 이름은 자동 연결하고 그 외는 자연 정렬로 2장씩 연결한다. 홀수 파일은 B 빈 슬롯으로 남기며 변환 대상에서 제외한다. 사용자에게 원본 쌍 검토를 안내한다. 쌍은 최대 50개이므로 각 쌍 두 슬롯 합계도 100개를 넘을 수 없다. 결과 파일명에서는 이미지 확장자를 두 번 제거하지 않는다.

미리보기는 AI의 원본/변환 결과 또는 두 장 비교의 원본 A/B/변환 결과, 4가지 바탕, 확대를 지원한다. 바탕색은 PNG 픽셀에 영향을 주지 않는다. 저장 이름 입력, 원본 교체, 선택/전체 다운로드를 제공한다. 반응형 레이아웃, 키보드 포커스 표시, 명명된 입력, aria-pressed, 상태 알림, native dialog의 포커스 제어·Escape 닫기를 사용한다.

## 개인정보·운영

외부 이미지 전송, 인증, analytics 이벤트가 없다. 메모리 내 작업이며 새로고침 시 사라진다. CSP는 same-origin 스크립트와 WASM 컴파일, 이미지 blob/data, worker blob을 허용한다. 모델의 고정 revision 다운로드를 위해 Hugging Face 및 hf.co 배포 도메인의 connect-src만 추가 허용한다. 실행 JS·WASM은 same-origin으로 제공하며 모델은 공개 CDN에서 직접 받아 브라우저 Cache API에 보관한다. 모델 파일은 앱 Git/Vercel 배포에 포함하지 않는다. 비공개 GitHub와 Vercel Hobby 개인 scope를 사용한다.

## 형식 변환 계약

- format=png|webp|jpg, jpegQuality=1..100(기본95), 기본 suffix=-converted.
- convert에서는 AI 모듈 로딩과 모델 다운로드가 없고 crop·floor·ceiling은 적용하지 않는다. 배경 제거 관련 옵션은 숨긴다.
- APNG acTL 청크를 감지해 형식 변경·배경 제거를 거부하고 convert PNG→PNG만 원본 보존한다. 실제 signature로 입력 형식을 판단하며, 같은 형식이면 검증 후 원본 File을 그대로 반환한다.
- PNG/WebP 사이의 변환은 Canvas premultiply 손실을 피하기 위해 원본 바이트를 전용 decoder로 읽고 무손실 encoder로 출력한다. WebP exact=1로 투명 픽셀 RGB도 보존한다. 16-bit PNG 및 저비트 인터레이스 PNG의 다른 형식 변환은 오류로 안내한다.
- JPG는 흰색 합성·손실 압축을 명시한다. 배경 제거가 켜져 있으면 JPG는 선택할 수 없으며, JPG 상태에서 켜면 PNG로 바꾼다.
- 형식 변경은 기존 결과를 무효화하며 파일 이름과 다운로드 버튼, ZIP 내 확장자를 함께 갱신한다.

## 수용 시나리오

- 최초 로드 시 배경 제거 switch unchecked, PNG 선택, AI 옵션 숨김.
- PNG→PNG는 원본 바이트와 동일. PNG→WebP→PNG는 RGBA 픽셀과 크기가 동일하고 ZIP CRC 통과.
- OFF→ON→OFF 상태 변경 후 결과가 무효화되고 배경 보존/제거 경로가 각각 적용됨.
- JPG는 실제 JPEG signature, 흰색 배경 합성, 손실 안내와 일치.


- 기본 예제 한 장으로 로컬 AI 투명 PNG 생성. 모델 다운로드 진행률, 모델 재사용, 원본 크기 유지, 기존 알파 보존 확인.
- 두 장 비교의 예제 두 장으로 800×800 투명 PNG 생성. 투명 배경, 부분 알파, 불투명 영역 공존.
- AI에서 이름 패턴과 관계없이 각각 변환되며 여러 PNG가 ZIP에 포함됨.
- 두 장 비교에서 4장 이상 다중 업로드가 쌍 목록으로 연결되고 순차 변환되어 ZIP에 모든 PNG 포함.
- 같은 저장 이름인 여러 쌍에 번호가 붙고 점이 포함된 버전 이름이 유지됨.
- 선택 해제한 쌍은 선택 변환·선택 ZIP에서 제외. 완료 전체 ZIP은 모든 성공 결과 포함.
- HEX/RGB 배경색, 임계값, floor/ceiling, off/auto/threshold crop가 연산에 반영.
- floor > ceiling 등 잘못된 옵션은 변환 불가. 잘못된 원본은 오류 표시 후 다른 쌍 계속 처리.
- 중지하면 다음 작업이 시작되지 않고 이미 완성한 PNG를 저장 가능.
- 데스크톱·모바일에서 컨트롤이 넘치지 않고 가이드 닫기/옵션 조작 가능.
- 프로덕션 빌드·타입 검사·린트 통과. 배포 후 외부 접속과 worker/ZIP 흐름 확인.
