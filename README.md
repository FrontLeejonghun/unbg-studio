# unbg studio

디자이너를 위한 브라우저 이미지 변환 작업 공간. **기본은 배경 제거 OFF, PNG 저장**입니다. 이미지 여러 장의 형식을 바꾸고 개별 파일 또는 ZIP으로 가져갈 수 있습니다. 배경 제거를 켜면 개인·비상업 용도로 무료인 [BRIA RMBG 1.4](https://huggingface.co/briaai/RMBG-1.4)를 사용자 기기에서 실행합니다. **두 장 비교 · unbg** 모드는 기존 difference matting의 모든 옵션을 제공합니다.

## 사용하기

1. PNG, JPG, 정적 WebP를 한 장 또는 여러 장 선택하거나 미리보기 영역에 드롭합니다.
2. 저장 형식을 PNG, WebP, JPG 중 선택합니다. 기본은 배경을 유지하며 크기·투명도·픽셀을 임의로 수정하지 않습니다.
3. 필요한 경우에만 `배경 제거`를 켭니다. 기본 자동 제거는 파일 한 장씩 처리하며 이름으로 묶지 않습니다.
4. `변환하기` 후 결과를 원본과 비교하고 개별 저장, 선택 ZIP, 완료 전체 ZIP으로 가져갑니다. `중지`로 현재 처리와 나머지 대기를 멈출 수 있습니다.

### 무손실 변환 범위

- 같은 형식으로 저장: 원본 파일 바이트를 그대로 저장하며 재압축·메타데이터 손실이 없습니다. 접미사는 기본 `-converted`입니다.
- PNG와 WebP: 디코딩된 8-bit 픽셀 기준 무손실. PNG는 fast-png, WebP는 libwebp의 `lossless=1`, `near_lossless=100`, `exact=1`로 인코딩합니다. 반투명·완전 투명 픽셀의 RGB도 유지합니다. 단순 확장자 이름 변경이나 Canvas의 손실 WebP 인코딩이 아닙니다.
- JPG: 손실 압축을 명확히 표시하고 품질 1~100을 제공합니다. 투명 영역은 흰색으로 합성합니다. 배경 제거 결과에는 PNG/WebP만 허용하며, JPG 선택 상태에서 배경 제거를 켜면 PNG로 전환합니다. JPG 원본→JPG는 품질 설정과 무관하게 원본을 유지합니다.
- 형식이 달라지는 경우 EXIF·ICC 프로파일 등 메타데이터는 보존하지 않습니다. JPEG 원본에 이미 생긴 손실은 복원하지 않습니다. 16-bit PNG와 저비트(1/2/4-bit) 인터레이스 PNG는 다른 형식으로 변환하지 않고 PNG로 원본 저장하도록 안내합니다.
- 배경 제거 OFF에서는 AI를 import하거나 모델을 다운로드하지 않으며 crop·floor·ceiling도 적용하지 않습니다.

### 선택형 배경 제거

AI 첫 실행에 모델 약 42 MiB와 실행 파일 약 13 MiB(전송 시 압축 가능)를 다운로드합니다. 진행률을 표시하며 브라우저 캐시가 유지되는 동안 재사용합니다. `예제로 시작하기`는 직접 만든 꽃 이미지 한 장을 제공합니다. AI는 피사체 경계를 추정하므로 반투명 그래픽의 원래 투명도를 정확히 복원하는 용도로는 두 장 비교 모드를 권장합니다.

### 두 장 비교 모드

작업 공간을 비우고 배경 제거를 켠 뒤 `두 장 비교 · unbg`를 선택합니다. 같은 크기·위치의 피사체를 흰색/검정 등 서로 다른 단색 배경 위에 준비합니다. `flower-white.png` / `flower-black.png`는 자동 연결하며 `light/dark`, `bg1/bg2`, `a/b`, `흰색/검정` 접미사도 지원합니다. 나머지는 파일명 자연 정렬 후 2장씩 연결합니다. 잘못 연결되거나 빠진 이미지는 A/B 슬롯을 눌러 교체합니다.

## 모든 unbg 옵션

| 원본 옵션 | 화면 | 기본값 |
| --- | --- | --- |
| `background1` | 배경 A 자동 감지 / HEX·RGB 직접 입력 / 컬러피커 | 네 모서리 자동 감지 |
| `background2` | 배경 B 자동 감지 / HEX·RGB 직접 입력 / 컬러피커 | 네 모서리 자동 감지 |
| `channelThreshold` | 채널 임계값, 숫자·슬라이더 | 10 (0–255) |
| `floor` | 투명도 하한 | 0 (0–1) |
| `ceiling` | 투명도 상한 | 1 (0–1) |
| `crop` 없음 | 원본 크기 유지 | 기본 |
| `crop: true` | 자동으로 여백 자르기 (`cropContent`) | 경계 가시 픽셀 밀도 1% |
| `crop: number` | 투명도 기준으로 자르기 (`cropTransparent`) | 선택 시 0.02 (0–1) |
| CLI `--output` | 선택한 이미지 저장 이름 + 공통 접미사 | `이름-converted.png` |

변환 옵션은 전체 작업에 적용되며 수정하면 기존 결과를 무효화합니다. 저장 이름과 접미사 변경은 이미 만든 결과를 유지합니다. 중복 이름은 번호를 붙여 ZIP에서도 덮어쓰지 않습니다. 두 장 비교 모드에서 감지된 배경색, 색 거리, 잘림 시작 임계값을 표시합니다. AI 모드에서는 실행 엔진을 표시하고, 공통으로 출력 크기와 용량을 보여줍니다. AI 모드는 BRIA의 전처리·마스크 min-max 정규화를 적용하고, `floor`, `ceiling`을 예측 마스크에 적용한 뒤 원본 알파를 곱하므로 기존 투명 영역을 보존합니다. 배경색·채널 임계값은 두 장 비교에서만 노출됩니다.

## 데이터와 비용

- BRIA RMBG 1.4는 `bria-rmbg-1.4` 비상업용 라이선스입니다. 사용자가 확인한 개인·비상업 용도에 사용하며, 상업적 이용은 BRIA와 별도 계약이 필요합니다. 모델 가중치는 변경·재배포하지 않고 제공자의 공개 q8 파일을 직접 내려받습니다.
- 서버 함수, 이미지 업로드, 데이터베이스, AI API, 외부 폰트, 분석 SDK를 사용하지 않습니다.
- `@huggingface/transformers@4.2.0`, ONNX Runtime Web, `unbg/core@1.1.0`를 사용해 Web Worker 안에서 디코딩·선택형 배경 제거·인코딩을 수행합니다. 유료 추론이나 인증 토큰이 필요하지 않습니다.
- AI 모델은 공개 Hugging Face 저장소에서 직접 다운로드합니다. 모델 revision은 `2ceba5a5efaec153162aedea169f76caf9b46cf8`, q8 ONNX 파일은 44,403,226 bytes로 고정합니다. 모델 다운로드는 Vercel의 데이터 전송량에 포함되지 않으며, 사이트·WASM 파일 전송에는 Vercel 무료 한도가 적용됩니다.
- 모델 다운로드 제공자는 IP 등 일반 접속 정보를 볼 수 있지만 사진은 전송하지 않습니다. 캐시 삭제, 시크릿 모드, 저장 공간 회수 시 다시 다운로드할 수 있습니다.
- 한 번에 한 작업을 처리하고 worker·모델은 배치와 재변환 사이에 재사용합니다. WASM CPU로 실행해 GPU 지원 여부와 관계없이 사용합니다. 중지·시간 초과·런타임 오류·작업 공간 비우기·앱 해제 시 worker를 종료합니다. ZIP도 로컬에서 만듭니다.
- 원본·결과는 탭의 메모리에만 있습니다. 새로고침·탭 닫기 전에 저장하세요. 삭제 시 Blob URL을 해제합니다.
- 개인 GitHub 비공개 저장소. 저장소 비공개와 사이트 접근 권한은 별개이며, 배포 URL은 접속 가능합니다.
- Vercel 개인 **Hobby**에 정적 배포합니다. 사용자가 개인·비상업 용도를 확인했습니다. 무료 플랜 한도에 종속되며 트래픽·배포 한도 초과 시 제한될 수 있습니다. 유료 플랜·부가 기능·도메인은 활성화하지 않습니다.
- 호스팅 제공자는 사이트 파일을 전달하기 위한 일반적인 접속 메타데이터를 처리할 수 있지만, 이미지 콘텐츠는 앱에서 전송하지 않습니다.

## 로컬 개발

Node 24 LTS, pnpm 10.33.4 사용.

```sh
pnpm install --frozen-lockfile
pnpm dev
pnpm check
pnpm build
pnpm preview
```

React + TypeScript + Vite. 한국어 단일 언어 UI이며 PO 카탈로그를 사용하는 앱이 아닙니다. [구현 계약](docs/spec.md)을 참고하세요.

## 제한

- 형식 변환·AI 작업 공간당 50장, 두 장 비교는 50쌍 / 100파일, 원본 합계 300 MB, 파일당 20 MB, 이미지당 1,600만 픽셀.
- PNG, JPG/JPEG, 정적 WebP 입력. 형식 변환·AI에서는 투명한 원본도 지원합니다. 두 장 비교에서는 투명한 원본을 거부하며, 모든 모드에서 애니메이션 WebP를 거부합니다. APNG는 배경 보존 PNG 원본 저장만 허용하고, 형식 변경·배경 제거는 거부합니다. PNG가 가장 적합합니다.
- 브라우저의 Canvas·createImageBitmap·Web Worker·OffscreenCanvas 지원이 필요합니다. 최신 데스크톱 브라우저를 권장합니다. 큰 배치는 기기 메모리에 따라 나누어 처리하세요.
- AI 마스크는 1,024×1,024에서 예측 후 원본 크기로 확대합니다. 머리카락, 유리, 가는 선, 반투명 영역 등은 손실·잔여 배경이 생길 수 있습니다. 속도와 최대 처리 크기는 기기 성능·메모리에 영향을 받습니다.
- 같은 형식의 원본 저장은 메타데이터·정밀도를 유지합니다. 형식 변환·배경 제거는 8-bit RGBA 경로이며 EXIF/ICC 프로파일을 보존하지 않습니다. AI 마스크 추론에는 Canvas 픽셀이 사용됩니다.
- 자동 자르기는 가시 픽셀이 드문 경계를 잘라낼 수 있습니다. 미리보기를 확인하거나 원본 크기를 유지하세요.

## 배포

개인 Vercel scope `frontleejonghuns-projects`에 연결합니다. `vercel.json`에 Vite 정적 빌드, 캐시·보안 헤더가 정의되어 있습니다. `pnpm build`에서 고정 버전 WASM 런타임을 public/vendor로 복사하며 생성물은 Git에서 제외합니다. `.env`와 비밀키는 필요하지 않습니다. GitHub 연동 후 main push가 배포를 트리거합니다.
